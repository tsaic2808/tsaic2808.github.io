- `_pages/about.md` — biography
- `_pages/research.md` — research overview
- `_pages/talks-teaching.md` — invited talks and teaching
- `_pages/data-modeling.md` — secondary quantitative profile
- `_pages/publications.md` — publication index
- `_pages/cv.md` — web CV
- `_publications/` — individual publication entries
- `_sass/_modern.scss` — custom design
- `_config.yml` — site settings and professional links
- `files/` — downloadable CV and publication list
